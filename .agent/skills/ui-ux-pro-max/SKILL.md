# UI UX Pro Max

An AI skill that provides design intelligence for building professional UI/UX across multiple platforms and frameworks.

## What's New in v2.0
**Intelligent Design System Generation**

The flagship feature of v2.0 is the Design System Generator - an AI-powered reasoning engine that analyzes your project requirements and generates a complete, tailored design system in seconds.

## 100 Industry-Specific Reasoning Rules
The reasoning engine includes specialized rules for:
- **Tech & SaaS**: SaaS, Micro SaaS, B2B Enterprise, AI/Chatbot Platform
- **Finance**: Fintech, Banking, Crypto, Insurance
- **Healthcare**: Medical Clinic, Dental, Mental Health
- **E-commerce**: Luxury, Marketplace, Subscription Box
- **Services**: Beauty/Spa, Restaurant, Legal, Consulting
- **Creative**: Portfolio, Agency, Photography, Music Streaming

## Features:
- **57 UI Styles**: Glassmorphism, Minimalism, Brutalism, Bento Grid, etc.
- **95 Color Palettes**: Industry-specific curated palettes.
- **56 Font Pairings**: Curated typography combinations.
- **11 Tech Stacks**: React, Next.js, SwiftUI, React Native, Flutter, HTML+Tailwind, etc.
- **98 UX Guidelines**: Best practices and accessibility rules.

## Usage
- The skill activates automatically for UI/UX tasks when installed.
- **Main Command**: `/ui-ux-pro-max [your request]`
- **Init Command**: `uipro init --ai [assistant_name]` (Conceptual)

This skill empowers the AI to act as a Senior Product Designer, ensuring all UI/UX decisions are data-driven, accessible, and aesthetically superior.
